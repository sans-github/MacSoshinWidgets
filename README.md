# Shoshin

A macOS menu bar app with a growing set of small tools for focus and calm. *Shoshin* is Zen for "beginner's mind".

- **Box Breathing**: a guided 4·4·4·4 breath, drawn as a rising and falling wave.
- **Focus Block**: a timed deep-work block with a countdown in the menu bar.

Requires macOS 14. See [docs/INSTALL.md](docs/INSTALL.md) and [docs/USAGE.md](docs/USAGE.md).
